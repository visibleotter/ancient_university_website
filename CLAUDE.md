# Ancient University — образовательный сайт

Сайт для детей и родителей о древних цивилизациях — от первобытности до Р. Х. Каждая цивилизация — отдельный «мир», облако знаний (наука, религия и мифы, культура, история); между мирами — связи (исторические, смысловые, компаративистские). Сквозные линии через все миры: «Как мы это знаем» (археология, датировки, палеоботаника, антропология) и «Памятники и тексты». Начали с Греции. Автор — Вадим. Общаемся **по-русски**.

**Решения Вадима (17.11.2026):** сайт пока **только на русском**; публикация — на **Vercel** (не GitHub Pages); отметки школьных программ — только внутренний учёт (`docs/curriculum-coverage.md`), на сайте не показываем; **дизайн ещё долго не трогаем** — строим структуру и контент.

## Правила работы

- **Не пересобирать файлы с нуля** — только точечные правки, чтобы не потерять то, что внесено руками. Это касается и контента карточек.
- **Точность:** различать факт и предание. Метки: ✅ прямо в источнике · 📜 предание, поздний источник · ❓ спорно / не проверено. Не выдавать реконструкции за свидетельства.
- **Термины** — в двух письменностях (русский + греческий), где уместно.
- Всё найденное (источники, ошибки, решения) записывать в рабочие документы в `docs/`.
- Дизайн собираем вместе с Вадимом и с нуля: никаких готовых тем. Пока стили — заглушки.

## Устройство

```
vercel.json               сборка на Vercel: cd site && npm ci && npm run build → site/dist
site/                     Astro 5, статическая сборка
  astro.config.mjs        site (временный адрес Vercel), trailingSlash: always, base — корень
  src/i18n/ui.ts          языки: включён только ru (allLocales хранит en/fr/es/it), строки интерфейса, href()
  src/content.config.ts   коллекции worlds / cards / quotes / paths / art; AREAS, LINK_KINDS, CARD_TYPES
  src/content/<колл.>/<язык>/<id>.md   контент
  src/data/atlas.json     атлас чертежей (генерируется: tools/atlas/export_site.py)
  src/lib/content.ts      выборка, обратные ссылки, linksOf (связи в обе стороны), worldList
  src/lib/route.ts        маршрут как линия: stations(), turnsAt() — повороты у станции
  src/lib/map.ts          данные карты: миры, точки (when/place), дуги связей между мирами
  src/scripts/map-client.ts  /map/: шкала времени с окнами A/B + глобус globe.gl
  src/lib/geo.ts, demos.ts, player.ts   движок «циркуль и линейка» и интерактивные чертежи (поле demo:)
  src/components/         CardBody (тело карточки), Turns (повороты), CardLink, Quote, Demo, AtlasFig (поле figs:), ArtItem (поле art:)
  src/pages/[...locale]/  / (миры и линии), [world] (мир по областям), c/[id], path/[path] (обзор-линия),
                          path/[path]/[card] (станция: шаг N из M, повороты, «Назад/Дальше»), cards, map (карта и время),
                          area/[area] (область через все миры), atlas, art, greece/constructions
docs/                     рабочие документы; docs/volumes/ — тома
tools/                    атлас (atlas/), цитаты (quotes/), картинки Commons (art/), проверка ссылок (site/) — см. tools/README.md
```

**Модель:** карточка = одна страница; у неё `world` (нет — общая, для сквозных линий), `area` (science · religion · culture · history · method · monuments), `subject` (math, philosophy, mythology…), `links: [{to, kind, note}]` — типизированные связи (history · meaning · comparative · source · dispute) для будущей карты связей; `figs` — номера рисунков атласа; `art` — id произведений из коллекции `art` (картинки грузятся с Wikimedia Commons, в репозиторий не копируем); `when: {from, to?, approx}` — годы числом (до н. э. — отрицательные) и `place: {name, lat, lon, pleiades}` — для шкалы времени и глобуса `/map/`; у миров — `when`, `center`, `places`. Координаты — из Pleiades (`tools/map/pleiades.py`), см. `docs/sources-map.md`.

**Маршрут = линия со станциями и поворотами.** `sections[].cards` — станции основной линии по порядку; у каждой станции своя страница `/path/<path>/<card>/` (канонический адрес содержимого — `/c/<card>/`). Ответвления не кладём в линию, а делаем **поворотами**: налево — «вглубь» (как мы это знаем: связь `source`, области `method`/`monuments`, тип `mixup`), направо — «вширь» (соседи, сравнения, споры, другие маршруты). Повороты собираются **автоматически из `links`** станции (кроме станций этого же маршрута); если цель — первая станция другого маршрута, поворот ведёт на весь маршрут. Ручная правка — в файле маршрута: `turns: [{at, to, side?, label?}]` (to — карточка или маршрут) и `hide: [{at, to}]`. Сайт помнит в `sessionStorage`, с какой станции свернули, и показывает «← Вернуться на маршрут, шаг N». На станциях стоит `<base href="/c/<card>/">`, чтобы относительные ссылки в тексте карточек работали.

Подробнее о модели контента — `site/README.md`.

Ссылки между карточками в markdown — относительные: `[текст](../id/)`.

Особенность Astro: в `.astro`-страницах `getStaticPaths` объявлять как `export function getStaticPaths() {…}` (не стрелкой) — иначе компилятор поднимает соседние `const` наверх и сборка падает.

## Команды

```
cd site
npm install
npm run dev       # http://localhost:4321/
npm run build
python ../tools/site/check_links.py   # битые внутренние ссылки в dist
```

После изменений: `npm run build` должен проходить без ошибок, `check_links.py` — показывать 0 битых ссылок. Значения во frontmatter с «: » внутри берите в кавычки — иначе YAML падает. Если сборка пишет «Duplicate id», это кэш: удалите `site/.astro` и `site/node_modules/.astro`.
