# Ancient University — образовательный сайт

Сайт о древнегреческой науке для детей и родителей: сначала раздел «Математика греков», потом мифы и философы. Автор — Вадим. Общаемся **по-русски**.

## Откуда берётся контент

Исследования ведутся отдельно, в чате claude.ai (проект «Education for the Courses»). Там лежат рабочие тома:

- `Математика_и_геометрия_греков.md` — главный источник для раздела (≈530 КБ): Азбука, Евдем, люди и открытия, Евклид §Г0–Г14, мифы, курс для 6–7 лет;
- `Ранние_греческие_философы.md`, `Мифология_Греции_кратко.md`, `Мифы_Греции_в_искусстве.md`.

Копии томов лежат в `docs/volumes/` (снимок на 17.11.2026). Главная версия — в проекте claude.ai; если там что-то менялось, попроси Вадима обновить копию. Атлас чертежей Евклида опубликован отдельно: https://claude.ai/artifact/QrDkCVE6AqK7syuNyHdvA4 (якоря `#fig-N`).

Источники по построениям в школьных программах — `docs/sources-constructions.md`.

## Правила работы

- **Не пересобирать файлы с нуля** — только точечные правки, чтобы не потерять то, что внесено руками. Это касается и контента карточек.
- **Точность:** различать факт и предание. Метки: ✅ прямо в источнике · 📜 предание, поздний источник · ❓ спорно / не проверено. Не выдавать реконструкции за свидетельства.
- **Термины** — в двух письменностях (русский + греческий), где уместно.
- Всё найденное (источники, ошибки, решения) записывать в рабочие документы в `docs/`.
- Дизайн собираем вместе с Вадимом и с нуля: никаких готовых тем. Пока стили — заглушки.

## Устройство

```
site/                     Astro 5, статическая сборка → GitHub Pages
  astro.config.mjs        site + base '/ancient_university_website', trailingSlash: always
  src/i18n/ui.ts          языки (ru без префикса; en/fr/es/it), строки интерфейса, href()
  src/content.config.ts   коллекции cards / quotes / paths
  src/content/<колл.>/<язык>/<id>.md   контент; нет перевода → русский с пометкой
  src/lib/content.ts      выборка с откатом на ru, обратные ссылки
  src/lib/geo.ts          движок «циркуль и линейка»
  src/lib/demos.ts        интерактивные чертежи по шагам (поле demo: в карточке)
  src/lib/player.ts       показ, шаги, перетаскивание точек
  src/pages/[...locale]/math/…   хаб, path/[path], c/[id], constructions, cards
.github/workflows/deploy.yml     деплой на Pages при пуше в main
docs/                     рабочие документы; docs/volumes/ — тома
tools/                    атлас (atlas/), конвейер греческих цитат (quotes/), генераторы — см. tools/README.md
```

Подробнее о модели контента — `site/README.md`.

Ссылки между карточками в markdown — относительные: `[текст](../id/)`.

Особенность Astro: в `.astro`-страницах `getStaticPaths` объявлять как `export function getStaticPaths() {…}` (не стрелкой) — иначе компилятор поднимает соседние `const` наверх и сборка падает.

## Команды

```
cd site
npm install
npm run dev       # http://localhost:4321/ancient_university_website/
npm run build
```

После изменений: `npm run build` должен проходить без ошибок; внутренние ссылки проверять (в dist не должно быть битых href).

## Git

- Рабочая ветка — `skeleton`; в `main` — через PR.
- Pages включается один раз: Settings → Pages → Source: GitHub Actions.
