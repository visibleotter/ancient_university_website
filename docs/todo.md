# Что осталось сделать (обновлено 18.11.2026)

## Картины к мифам (`/path/myths-in-art/`)
Сделано: 31 новая карточка мифов и маршрут «Мифы Греции в искусстве» (38 станций). Привязано **160 картин** Нового времени к 26 карточкам из тома `docs/volumes/Мифы_Греции_в_искусстве.md`. Записи `site/src/content/art/ru/<карточка>-art-NN.md`, изображения грузятся с Commons.

Осталось:
1. **≈ 180 картин ещё не привязаны.** Поиск по Commons остановлен на 260 из 350 записей (Wikimedia ограничивает частоту запросов). Без картин пока: Геракл (обе карточки), Эдип, Атриды, троянская война (`achilles`, `hector-andromache`, `iliad-ring`, `trojan-horse`), «Киприи» (`trojan-war-prehistory`), Одиссей. Часть записей из первых 260 тоже без файла: поиск ничего не нашёл или вернул работу другого художника.
   - Скрипты и данные — в `tools/art/myths/`:
     - `art_extract.py` — поиск на Commons, долгий, лучше запускать на ночь;
     - `art_heracles.py` — досбор раздела «Геракл»;
     - `art_build.py` — раскладка по карточкам;
     - `art_write.py` — запись в `art/ru`.
   - ⚠ `art_write.py` при повторном запуске пропускает уже записанные файлы Commons, но нумерацию NN начинает заново. Перед повтором сначала доработать скрипт: начинать с последнего номера.
2. **Лицензии и авторы снимков не проверены** (`art_build.py`, флаг `VERIFY = False`). Для картин XV–XIX вв. это почти всегда общественное достояние, но у фотографий скульптур (Бернини, Канова, Торвальдсен, Фальконе) лицензия бывает CC BY-SA и требует указать автора. Включить `VERIFY = True`, когда API Commons отпустит, и дописать `credit`/`license`.
3. **Подписи к картинам пока шаблонные.** Стоит дописать, что именно рассматривать на картине, как в старых записях (`goya-saturn`, `botticelli-venus`).
4. **Античные изображения из тома** (вазы, рельефы, мозаики — ссылки Theoi) не обработаны: у них нет прямых файлов Commons, нужен отдельный поиск.
5. Выборочная проверка: 25 картин из 160 совпадают с названиями. Но поиск брал первый файл того же художника, и где-то может оказаться не та работа. Пролистать `/art/`.
