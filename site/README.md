# Сайт «Древний университет» — исходники

Astro 5, статическая сборка; публикация — Vercel (`vercel.json` в корне). Дизайн пока черновой: логика отдельно, оформление сделаем потом.

```
npm install
npm run dev      # http://localhost:4321/
npm run build    # → dist/
```

## Языки

Пока включён только русский (`locales` в `src/i18n/ui.ts`). Механизм языков сохранён: `ru` без приставки, остальные — `/en/…` и т. д.; если перевода записи нет, показывается русский оригинал с пометкой. Строки en/fr/es/it лежат в `ui.ts`, но новых ключей в них нет — перед включением языка их нужно дописать.

## Устройство: миры, области, линии

- **Мир** (`worlds`) — цивилизация, «облако знаний»: Греция, Египет, Месопотамия, Хетты, Израиль, Индия, Китай, Япония, Первобытность. `status: active | planned`. Адрес — `/<id>/`.
- **Область** (`area` у карточки и маршрута): `science` · `religion` (вкл. мифы) · `culture` · `history` внутри мира и две **сквозные линии** через все миры: `method` («Как мы это знаем») и `monuments` («Памятники и тексты»). Адрес области через все миры — `/area/<area>/`.
- **Тема** (`subject`): `math`, `philosophy`, `mythology`… — группировка внутри области на странице мира.
- **Связи** (`links: [{to, kind, note}]`): `history` — влияние, контакт; `meaning` — тот же вопрос; `comparative` — сходный миф или образ; `source` — откуда знаем; `dispute` — спор. Показываются на обеих карточках; из них потом соберём карту связей.

## Контент (раздел «Математика греков»)

Всё лежит в `src/content/<коллекция>/<язык>/<id>.md`; схема — в `src/content.config.ts`.

| Коллекция | Что это | Адрес |
|---|---|---|
| `worlds` | мир-цивилизация | `/<id>/` |
| `cards` | карточка — самая мелкая единица: человек, понятие, теорема, построение, опыт, идея, миф, персонаж, памятник, место, событие, метод | `/c/<id>/` |
| `quotes` | цитата из источника: греческий текст, перевод, место, назван ли Евдем | вставляется в карточки |
| `paths` | маршрут — цепочка карточек по разделам | `/path/<id>/` |
| `art` | произведение искусства: музей, номер, файл Wikimedia Commons, автор снимка, лицензия, ⚠ | вставляется в карточки (`art:`), все — `/art/` |

У карточки есть метки: тип, возраст (`6-7`, `8-10`, `11-15`), темы, надёжность (✅ 📜 ❓), место у Евклида, связанные карточки, а у построений — где задача встречается в школьных программах (поле `curricula`, только для внутреннего учёта: на сайт не выводится, сводка — `docs/curriculum-coverage.md`). Из меток собираются каталог построений (`/greece/constructions/`) и список всех карточек (`/cards/`).

Чертежи атласа: поле `figs: [N]` (номер «Рис. N», как в томе и в опубликованном атласе); данные — `src/data/atlas.json`, пересобирается `python tools/atlas/export_site.py`. Все рисунки — `/atlas/`.

Картинки к сюжетам на сайт не копируются: `ArtItem` грузит их с Commons по имени файла через `Special:FilePath`; автор снимка и лицензия выводятся под картинкой.

Ссылки между карточками в тексте пишутся относительно: `[текст](../id-карточки/)`.

## Интерактивные чертежи

`src/lib/geo.ts` — мини-движок «циркуль и линейка» (точки, окружности, прямые, пересечения, углы); `src/lib/demos.ts` — сами чертежи по шагам; `src/lib/player.ts` — показ, листание шагов, перетаскивание точек. Карточка подключает чертёж полем `demo: <id>`.

## Маршрут: станции и повороты

- `sections[].cards` — станции основной линии. Страница станции: `/path/<path>/<card>/` (`src/pages/[...locale]/path/[path]/[card].astro`): «шаг N из M», мини-линия, повороты слева и справа, «Назад / Дальше». Обзор `/path/<path>/` рисует линию с отростками-поворотами.
- Повороты считает `src/lib/route.ts` (`turnsAt`): сначала ручные `turns` из файла маршрута, потом автоматические из `links` станции; `hide` убирает лишнее. Налево («вглубь») — связь `source`, цель в областях `method`/`monuments` или тип `mixup`; остальное направо («вширь»). Если цель — первая станция другого маршрута, поворот ведёт на маршрут целиком.
- Пример ручных поворотов:

```yaml
turns:
  - { at: pyramid-shadow, to: cosmic-ladder, side: right }   # на маршрут
  - { at: thales, to: sources, side: left, label: откуда мы знаем }
hide:
  - { at: theogony, to: kumarbi }
```
