# Сайт «Древний университет» — исходники

Astro 5, статическая сборка для GitHub Pages. Дизайн пока черновой: логика отдельно, оформление сделаем потом.

```
npm install
npm run dev      # http://localhost:4321/ancient_university_website/
npm run build    # → dist/
```

## Языки

`ru` открывается без приставки в адресе, `en`, `fr`, `es`, `it` — по `/en/…` и т. д. Строки интерфейса лежат в `src/i18n/ui.ts`. Если перевода записи нет, показывается русский оригинал с пометкой.

## Контент (раздел «Математика греков»)

Всё лежит в `src/content/<коллекция>/<язык>/<id>.md`; схема — в `src/content.config.ts`.

| Коллекция | Что это | Адрес |
|---|---|---|
| `cards` | карточка — самая мелкая единица: человек, понятие, теорема, построение, опыт, миф | `/math/c/<id>/` |
| `quotes` | цитата из источника: греческий текст, перевод, место, назван ли Евдем | вставляется в карточки |
| `paths` | маршрут — цепочка карточек по разделам («Фалес и начала геометрии») | `/math/path/<id>/` |

У карточки есть метки: тип, возраст (`6-7`, `8-10`, `11-15`), темы, надёжность (✅ 📜 ❓), место у Евклида, связанные карточки, а у построений — где задача встречается в школьных программах. Из этих меток собираются каталог построений (`/math/constructions/`) и список всех карточек (`/math/cards/`).

Ссылки между карточками в тексте пишутся относительно: `[текст](../id-карточки/)`.

## Интерактивные чертежи

`src/lib/geo.ts` — мини-движок «циркуль и линейка» (точки, окружности, прямые, пересечения, углы); `src/lib/demos.ts` — сами чертежи по шагам; `src/lib/player.ts` — показ, листание шагов, перетаскивание точек. Карточка подключает чертёж полем `demo: <id>`.
