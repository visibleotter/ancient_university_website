# Инструменты

Скрипты, которыми делались тома и атлас. Они нужны, чтобы повторить или продолжить работу, а не для сборки сайта.

## atlas/ — атлас чертежей Евклида

- `figs.py` — 49 чертежей в SVG (цвета Бирна: красный, жёлтый, синий, чёрный);
- `meta.py` — к каждому рисунку: тема, возраст, раздел тома, «как читать», «что сделать руками», «где в жизни»;
- `atlas.py` — нумерация и порядок; `guide.py` — собирает страницу `atlas.html` с карточками, фильтрами по теме и возрасту и переходом к рисунку по номеру;
- `export_site.py` — выгружает рисунки и подсказки для сайта в `site/src/data/atlas.json` (запускать после правок `figs.py` / `meta.py`);
- `atlas.html` — готовая страница (она же опубликована: https://claude.ai/artifact/QrDkCVE6AqK7syuNyHdvA4, якоря `#fig-N`).

```
cd tools/atlas && python3 guide.py   # пересобирает atlas.html рядом
```

## quotes/ — греческие цитаты для томов

Греческий текст берётся из TEI-изданий; сами корпуса в репозиторий не входят (≈150 МБ):

```
cd tools/quotes
git clone --depth 1 https://github.com/PerseusDL/canonical-greekLit pgl
git clone --depth 1 https://github.com/OpenGreekAndLatin/First1KGreek f1k
pip install lxml
```

- `src.py` — поиск по корпусам без учёта ударений: `python3 src.py 'pgl/data/tlg0031/**/*.xml' 'слова поиска'`;
- `quotes.py`, `gquotes.py`, `euc.py` — словари цитат (id → источник, место, греческий текст, перевод);
- `lquotes.py` + `build_logic.py` — цитаты и сборка тома «Начала логики» (`templates/t_logic.md` → `Начала_логики.md`);
- `build.py` — подставляет цитаты в шаблоны: `{{Q:ID}}` → блок цитаты; `[[N]]` → ссылка на рисунок атласа;
- `templates/` — шаблоны глав (`t_*.md`), из которых собирались первые версии томов;
- `sections/` — разделы, вставленные в том позже (Евдем, посох Якова, Луна и Солнце, лестница расстояний, Азбука, Перельман);
- `merge.py` — разовый скрипт, которым три математических файла слиты в один том (исторический: пути в нём старые);
- `batch1.py`, `gq_probe.py` — вспомогательные проверки.

Правило: тома дальше правятся точечно, а не пересобираются из шаблонов — в них есть ручные правки.

## site/

- `check_links.py` — после `npm run build` проверяет внутренние ссылки в `site/dist` (код выхода 1, если есть битые);
- `gen_constructions.py` — разовый генератор карточек-построений для сайта. Источник истины теперь — сами `.md` в `site/src/content/cards/ru/`; повторно не запускать (перезапишет ручные правки).

## art/ — картинки с Wikimedia Commons

- `commons.py search "запрос"` — первые файлы по запросу; `commons.py info "Файл.jpg"` — автор, лицензия, размер. Проверяйте каждый файл перед тем, как вписать его в `site/src/content/art/ru/<id>.md` (поля `commons`, `credit`, `license`).
- API Commons ограничивает частоту: запрашивайте пачкой и с паузами. Если Python не выходит в сеть, а `curl` выходит, скрипт сам переключится на `curl`.
